# Technology Stack

| Layer | Technology | Purpose |
|-------|------------|---------|
| Programming Language | Python 3.10+ | Core application logic |
| Frontend / UI | Streamlit | Web interface for story input and comic preview |
| Generative AI (Text) | Google Gemini (gemini-2.5-flash) | Story-to-panel script generation in JSON |
| Generative AI (Image) | Google Gemini Image Model (gemini-2.5-flash-image) | Comic panel illustration generation |
| AI SDK | google-genai | Python client for Gemini API |
| Image Processing | Pillow (PIL) | Speech bubbles, captions and page layout |
| Export | ReportLab / img2pdf | PDF generation |
| Configuration | python-dotenv | API key management |
| Version Control | Git & GitHub | Team collaboration and code hosting |
| IDE | VS Code / Google Colab | Development and testing |
| Deployment | Streamlit Community Cloud | Public hosting of the app |
