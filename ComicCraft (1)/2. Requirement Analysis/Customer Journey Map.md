# Customer Journey Map

**Persona:** Aarav, a school teacher / hobby storyteller with no drawing skills who wants to create a comic from a story idea.

| Stage | Customer Action | Touchpoint | Customer Feeling | Pain Point | Opportunity (ComicCraft) |
|-------|-----------------|------------|------------------|------------|--------------------------|
| Awareness | Learns that AI can create comics | Search / social media / college | Curious | Does not know which tool to use | Simple landing page explaining the tool |
| Consideration | Opens ComicCraft and reviews features | Web app home page | Interested | Fears complex setup | No-login, one-page interface |
| Input | Enters story idea, characters, style and panel count | Story input form | Excited | Unsure how to describe the story | Placeholder examples and sample prompts |
| Script Generation | Reviews AI-generated panel script | Script preview screen | Impressed | Script may not match idea | Editable script before image generation |
| Image Generation | Waits for panel illustrations | Panel gallery | Anxious while waiting | Waiting time and inconsistent characters | Progress bar and character sheet reuse |
| Review & Edit | Edits dialogue or regenerates a panel | Panel editor | Engaged | Wants to fix a single panel | Per-panel regenerate and edit option |
| Export | Downloads final comic as PDF / PNG | Export button | Satisfied | Poor quality output | High-resolution PDF and PNG export |
| Sharing | Shares comic with class or friends | Downloaded file | Proud | Watermark or format limits | Clean output ready to share |
